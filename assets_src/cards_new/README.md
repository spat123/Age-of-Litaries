# Новые рисунки карточек

Сюда кладутся картинки прямо из генератора: квадрат 1:1, один предмет на белом фоне.

Имя файла — имя рисунка со страницы `refs/kartinki.html` (оно же в `assets_src/CARDS.md`), например `g_coins.png`.

Потом из корня репозитория:

```bash
python3 web/tools/cut_bg.py
```

Скрипт уберёт белый фон, обрежет поля, уменьшит картинку до 512 точек и положит её в `web/assets/cards/` в формате webp. Игра подхватит рисунок сама.

Скрипт убирает и белые «дырки» внутри предмета: между ножек табуретки, в ручке кружки, в кольце ключей. Белые части самого предмета он не трогает: у генератора они с оттенком, а фон чисто-белый. Если скрипт всё же продырявит что-то нужное, имя рисунка вписывается в `KEEP_INNER` в начале скрипта.

Запасные варианты лежат в `assets_src/cards_spare/`.
