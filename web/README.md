# web — игра на Phaser

«Сэр Баг» (главы 0–6, от рождения до пещеры дракона) в браузере. Сюжет и числа игра берёт прямо из папки [`../story/`](../story/README.md): своих копий текста здесь нет.

## Запустить

```bash
npm --prefix /Volumes/Work/Age-of-Litaries/web run dev
```

Потом открыть в браузере `http://localhost:5173`. В первый раз перед этим нужно один раз поставить зависимости:

```bash
npm --prefix /Volumes/Work/Age-of-Litaries/web install
```

Собрать всю игру одним файлом для показа (кладётся в `refs/igra.html`, в git не идёт):

```bash
npm --prefix /Volumes/Work/Age-of-Litaries/web run single
```

## Как добавить картинку

Достаточно положить файл с нужным именем — код менять не надо.

| Что | Куда | Имя файла |
|-----|------|-----------|
| Картинка карточки | `assets/cards/` | как в поле `art` в `story/*.json`, например `o_goose.webp` |
| Фон сцены | `assets/bg/` | как в поле `bg`, например `bg_home_day.webp` |
| Значок показателя | `assets/icons/` | `body.png`, `mind.png`, `gold.png`, `rep.png` |

Полный список нужных картинок — в конце [`../story/BOOK.md`](../story/BOOK.md). Пока картинки карточки нет, на её месте стоит временный значок.

Фоны переносит скрипт: `python3 web/tools/prepare_assets.py`. Он берёт картинки из `assets_src/art/backgrounds_x2` (увеличенные), а если увеличенной нет — из `assets_src/art/backgrounds`, и кладёт их в игру шириной до 1920 точек. Готовые не трогает; чтобы пересобрать фон заново, назови его: `python3 web/tools/prepare_assets.py bg_well`. Высокий фон для телефона называется `<имя>_tall.png`; если он есть, на телефоне игра покажет его. Какие фоны нужны и запросы для них — `assets_src/BACKGROUNDS.md` и страница `refs/fony.html`. У мест без своего рисунка стоит запасной фон из поля `now` в `story/bg.json`.

Генератор отдаёт фоны шириной 1376 точек, а экран игры — 1920. Чтобы фон не был мыльным, его увеличивает вдвое программа Upscayl (должна быть установлена), потом `prepare_assets.py` уменьшает его до ширины экрана:

```bash
python3 web/tools/upscale_bg.py bg_well
```

```bash
python3 web/tools/prepare_assets.py bg_well
```

Без имени `upscale_bg.py` увеличивает все фоны, у которых увеличенного ещё нет. Модель по умолчанию даёт чистый контур и ровную заливку; `--model high-fidelity-4x` оставляет зерно. Увеличенные фоны лежат в `assets_src/art/backgrounds_x2` и в git не идут.

Картинку можно нарисовать и через Codex (он входит в приложение ChatGPT и работает от его аккаунта; каждая картинка тратит лимит):

```bash
python3 web/tools/codex_image.py --out assets_src/cards_new/o_scar.png --ref refs/ui_ref/style_1_izba.png "запрос"
```

Опорные картинки (`--ref`) в запросе можно звать `@img1`, `@img2`, как на страницах с запросами. `--size wide` или `tall` — для широкой или высокой картинки.

Рисованные вещи интерфейса (лист, карточка, кнопки, пропуск и другие) лежат в `assets_src/ui_new/`. Скрипт убирает фон, делит картинки с несколькими вещами, у карточки вырезает окно и пишет края, которые не растягиваются, в `assets/ui/ui.json`:

```bash
python3 web/tools/cut_ui.py
```

С `--preview папка` он ещё нарисует, как каждая вещь растягивается. Если вещи нет, игра рисует её кодом, как в наброске.

Если картинка желтит, её правит скрипт (он же печатает «жёлтость» до и после):

```bash
python3 web/tools/fix_yellow.py вход.png web/assets/bg/имя.webp 1920
```

Новые рисунки карточек кладутся в `assets_src/cards_new/` под именем рисунка (список и запросы — `assets_src/CARDS.md` и страница `refs/kartinki.html`). Скрипт убирает белый фон, заодно белые «дырки» внутри предмета (между ножек табуретки, в ручке кружки), и кладёт рисунки в `assets/cards` в формате webp:

```bash
python3 web/tools/cut_bg.py
```

Музыку готовит скрипт (нужен ffmpeg; берёт мелодии из `assets_src/audio/bgm`, ужимает и кладёт в `assets/audio`):

```bash
python3 web/tools/prepare_audio.py
```

Снять кадры игры в файлы (нужен Chrome; игра или её сборка одним файлом открывается без окна):

```bash
node web/tools/shot.mjs http://localhost:5173 /tmp/shots "w3000,s:start,1,w900,s:result,n,w900,s:next"
```

Первое `n` проходит заставку, второе выбирает первую кнопку главного меню. Шаги: цифра — выбрать карточку, `n` — «Дальше», `w500` — подождать, `s:имя` — сохранить кадр, `e:код` — выполнить код на странице (без запятых).

## Что где

| Файл | Что внутри |
|------|-----------|
| `src/data.ts` | Подключает сюжет из `story/` |
| `src/rules.ts` | Правила игры без экрана: показатели, карточки, подписки, смерть, Небесная HR. Перенос класса `Life` из `story/tools/build.py` |
| `src/GameScene.ts` | Главный экран на Phaser: фон, текст, карточки, переворот, показатели, рука |
| `src/ui.ts` | Детали интерфейса как вещи: свиток, бирки, дощечки, штамп, холодная табличка. Цвета и шрифты. Вид описан в [`../ui_design.md`](../ui_design.md) |
| `src/overlay.ts` | Длинные тексты обычной вёрсткой поверх игры: личное дело, смерть, Небесная HR, список исправлений |
| `src/assets.ts` | Подключение картинок и временные значки |

## Проверка

В консоли браузера:

```js
await autoplay(3000, 3)
```

Робот проживает жизни наугад и возвращает итоги. Доля дошедших до столицы должна совпадать с `python3 story/tools/build.py` (сейчас 45% и 44%).

Клавиши в игре: цифры 1–9 выбирают карточку, пробел или Enter — «Дальше».

## Что временное и чего ещё нет

- Картинки карточек — временные значки, кроме деревянного смартфона.
- Детали интерфейса (свиток, бирки, карточки, кнопки, штампы) нарисованы кодом. Промпты для настоящих — в `ui_design.md`.
- Есть заставка, главное меню («Продолжить», «Новая игра», «Что я уже видел», «Настройки») и кнопка «Меню» во время игры. Всё нарисовано кодом.
- Лента пути: в начале каждой главы (кроме сборки мира) и по кнопке «Путь» в меню. Остановки берутся из полей `place`, `place_bg`, `place_x` глав в `story/`; отметки прошлых жизней лежат в памяти браузера в `sirbug.meta.v1` (поле `path`) и стираются при «Новой игре». Вёрстка — `pathHtml` в `src/overlay.ts`, стили — в `index.html`.
- Музыка: три мелодии — меню, деревня (главы 0–4), столица (главы 5–6). Включается после первого нажатия: раньше браузер не разрешает. Настройки (музыка, громкость) лежат в памяти браузера, ключ `sirbug.settings.v1`. Звуков нажатий и событий нет.
- Сборка одним файлом (`refs/igra.html`) с музыкой весит около 23 МБ.
- Сохранение есть: игра запоминает место перед каждой сценой и в конце жизни (память браузера, ключ `sirbug.save.v1`). После перезагрузки спрашивает «Продолжить» или «Начать заново». Сцена после перезагрузки начинается сначала. Если сюжет изменился и сохранение к нему не подходит, игра молча начинает заново (`checkSave` в `src/rules.ts`).
- Нет портретов говорящих.
- Конец жизни идёт по шагам: чем кончилась (смерть или концовка) → «Итог жизни» → Небесная HR → наследство (если титулов несколько, подарок выбирает игрок) → «Что переходит в следующую жизнь» → список исправлений. Всё это пока простые окна и обычные карточки.
- Игра помнит, какие концовки, смерти и титулы игрок уже видел за все жизни (память браузера, ключ `sirbug.meta.v1`). «Начать заново» это не стирает.
- Есть высокий экран для телефона (1080×1920): он включается сам, если экран выше, чем шире. Проверен на размере телефона в браузере, на настоящем телефоне — нет. Фоны нарисованы широкими, поэтому на высоком экране от них виден только кусок посередине.
- Все шесть глав написаны. У игры есть конец: после кофейни, где герой не ответил маме, можно остаться — тогда «Конец» и главное меню с пометкой «Игра пройдена».
