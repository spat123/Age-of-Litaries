# Опоры для рисования вещей интерфейса

Папку собирает `sh refs/tools/make_ui_refs.sh`. Здесь два вида картинок.

## Рисовка: `style_*.png`

Три наших фона в полном размере. С них генератор берёт манеру рисунка: контур, плотный цвет, тени.

| Файл | Что это |
|------|---------|
| `style_1_izba.png` | Изба вечером. Тот самый образец рисовки, который выбрал автор |
| `style_2_kolybel.png` | Родители у колыбели: много дерева, ткани и посуды |
| `style_3_peschera.png` | Пещера дракона: золото, камень, холодные цвета |

Достаточно одной. Если рисовка «плывёт», подставь две.

Чужие игры как опору на рисовку не подставляем: у нас правило брать у них только приёмы, а не вид.

Мои наброски каждой вещи на белом фоне. С них генератор берёт форму и пропорции. Номер совпадает с номером запроса в `ui_design.md`, раздел 8.

## Как подставлять в Magnific

По справке Magnific у опор есть виды: Style, Character, Object, Color, Camera, Effects, и их можно сочетать. Сам интерфейс я не проверял.

1. Первой приложи картинку `style_…`: в запросе она названа `@img1`, это рисовка.
2. Второй приложи картинку `shape_…`: в запросе она названа `@img2`, это форма вещи.
3. Запрос возьми на странице `refs/veshchi.html`: там есть варианты без картинок, с одной и с двумя, и под каждой вещью написано, какие файлы приложить.

Если с двумя картинками выходит хуже, переключи страницу на одну: форма в запросе описана и словами.
